# 🏃 公園間歇快走慢跑教練

依間歇訓練理論設計的快走慢跑 App，可以裝在 Android 手機主畫面使用。

**👉 立即使用：<https://chahan1.github.io/walk/>**

## 主要功能
- **一週課表**：輕鬆走跑、挪威式 4×4、恢復快走、節奏閾值、30/30 短間歇／坡道衝刺（隔週輪替）、自由變速。
- **4 個等級**：從「走多跑少」到「以跑為主」，App 依紀錄建議升級或放慢。
- **自訂時間**：20–90 分鐘或自訂 15–150 分鐘，自動重新分配暖身、間歇組數與收操。
- **活潑的新介面**：今天的課表用代表色大卡片呈現，上面的高低起伏圖顯示每一段的強度；本週七天用彩色方塊一眼看完。
- **背景模式**：整堂課做成一條音軌播放並以音軌計時，關閉螢幕也有提示音（快走一長聲、慢跑兩聲、快跑急促三聲，換段前 3 秒倒數）。
- **通知提醒**：每換一段發通知，手機或小米手環會震動；可選換段前 5／10 秒先提醒。
- **英語練習模式**：手機完全靜音，只靠通知震動；可搭配英語學習筆記本使用。英語筆記本播放例句時，本 App 會自動讓出聲音並改用時鐘計時。
- **紀錄**：每次運動的時間、RPE、身體感覺，本週次數與連續天數。

## Tabata 時間指導器（tabata.html）
- 網址：<https://chahan1.github.io/walk/tabata.html>。
- **切換運動模式**：三個畫面最上方都有「間歇快走｜HIIT｜Tabata」切換列；間歇 App「設定」裡也有「運動模式」。選了會記住，下次從主畫面打開 App 會直接進入上次的模式。
- **畫面**：首頁只有模式選擇、一張計畫卡（全長、每段長度、回合數）和「開始」按鈕；時間、動作、開始方式、提示等設定都收在右上角的設定裡，Tabata 說明收在 ⓘ 裡。
- **預設模式**：經典 Tabata（20 秒／10 秒 × 8，約 4 分鐘）、adidas 15 分鐘（兩個動作交替，3 組，組間 1 分鐘）、入門版（20 秒／20 秒 × 8）、自訂。
- **時間自由設定**：準備、運動、休息、回合數、組數、組間休息、緩和都能調；「逐段調整長度」還能單獨改任何一段的秒數。
- **下一段怎麼開始**：自動接續（可關閉螢幕，提示音做在音軌裡）、每組結束等我、每段都等我（按「開始下一段」才計時）。
- **記住自訂時間**：在「自訂」改過的時間（包含逐段調整和動作名稱）會自動記住；先選其他預設模式，之後再點「自訂」就會還原上次的設定，卡片上也會顯示上次的時間。
- **震動提醒**：每回合運動時間一到就長震兩下；運動開始短震三下；運動的最後 3 秒每秒短震一下（螢幕亮著時，Android）。設定裡有「測試震動」按鈕。螢幕關閉時改發通知，手機和小米手環都會震動（設定裡要先「允許通知」）。
- 動作名稱用逗號分開，運動段會依序輪流並用語音念出；也可選英文提示。

## HIIT 高效燃脂（hiit.html）
- 網址：<https://chahan1.github.io/walk/hiit.html>，三個畫面最上方都有「間歇快走｜HIIT｜Tabata」切換列。
- **五個方案**（都含熱身與緩和）：入門快走爬坡（30 秒／90 秒 × 6，低衝擊）、公園跑步 10×1 分鐘（Little 與 Gibala）、挪威 4×4（Helgerud 2007，心肺效果最強）、燃脂 30/30（10 回合 × 2 組）、徒手循環（5 個動作各 1 分鐘，可選一律低衝擊）。
- **四個階段**：第 1～2 週、3～4 週、5～6 週、7 週起，每次只加一點回合或時間。App 從第一次做高強度開始算週數並標示「建議」；連續兩次整體 RPE 9 以上或回報不舒服，就不升級。第 7 週起不再加量，改提高速度或坡度。
- **強度提示**：每段畫面與語音都會說 RPE 和說話測試（例如「只能說幾個字」），不需要心率帶。
- **安全**：第一次使用先做安全檢查；每次開始前確認今天身體狀況，並提醒停止運動的警訊。
- **頻率**：HIIT、Tabata、間歇快走的快跑課（4×4、30/30、坡道）共用一份高強度紀錄（`hi_log`）。距離上次不到 48 小時、前 2 週已做過 1 次、或 7 天內已滿 2 次時會提醒（不強制）。
- **結束後**：用 0～10 分記錄整體有多累，紀錄在設定裡可以看。
- **週排程**：間歇快走「設定 → 搭配 HIIT 的週排程」（預設開）：週二、週五是 HIIT 日，其他天輕鬆走跑，週日恢復。HIIT 日的今天頁會出現「去 HIIT」；不到 48 小時則提醒改做輕鬆走跑。關掉就回到原本的間歇週計畫。
- 震動與通知和 Tabata 相同（運動時間一到長震兩下）。

## Android App（測試版）
- 下載：<https://github.com/chahan1/walk/releases/download/android-latest/walk-coach.apk>（用手機開啟，允許「安裝不明來源的應用程式」）。
- App 是一個外殼，畫面直接載入本網站，所以網頁更新會自動生效；只有原生功能改動時才需要重新安裝。
- **原生計時服務**（`android/`）：間歇快走、HIIT、Tabata（自動接續）開始後，計時、震動、語音都交給 Android 前景服務，不再播放背景音軌。
  - 提示出聲時向系統要求「暫時降低其他 App 音量」，英語記事本的例句只會短暫變小聲，不會被暫停。
  - 震動用鬧鐘類別，關螢幕也會震，不受「觸感回饋」設定影響；英語練習模式只震動不出聲。
  - 通知列可以暫停、跳下一段、結束；換段也會發提醒通知給小米手環。
- App 的紀錄和瀏覽器版分開存放，需要的話用「紀錄 → 匯出／匯入」搬過去。
- 打包：推送 `android/` 後 GitHub Actions（`.github/workflows/android.yml`）自動產生 APK 並更新 Release。簽章檔 `android/app/walkcoach.jks` 放在倉庫裡，確保每一版都能直接覆蓋安裝（只限自用）。

## 第一次使用（小米手機）
1. 用 Chrome 開啟 <https://chahan1.github.io/walk/>，右上選單 →「加到主畫面」。
2. 手機「設定 → 應用程式 → Chrome → 省電策略」改成「無限制」。
3. 要用手環：「小米運動健康」→ 手環 → 應用通知 → 開啟 Chrome。
4. App「設定」頁按「允許通知」，再按「測試手環震動」，10 秒內鎖上螢幕確認會震動。
