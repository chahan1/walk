# 🏃 公園間歇快走慢跑教練

依間歇訓練理論設計的快走慢跑 App，可以裝在 Android 手機主畫面使用。

**👉 立即使用：<https://chahan1.github.io/walk/>**

## 主要功能
- **一週課表**：輕鬆走跑、挪威式 4×4、恢復快走、節奏閾值、30/30 短間歇／坡道衝刺（隔週輪替）、自由變速。
- **4 個等級**：從「走多跑少」到「以跑為主」，App 依紀錄建議升級或放慢。
- **自訂時間**：20–90 分鐘或自訂 15–150 分鐘，自動重新分配暖身、間歇組數與收操。
- **活潑的新介面**：今天的課表用代表色大卡片呈現，上面的高低起伏圖顯示每一段的強度；本週七天用彩色方塊一眼看完。
- **背景模式**：整堂課做成一條音軌播放並以音軌計時，關閉螢幕也有提示音（快走一長聲、慢跑兩聲、快跑急促三聲，換段前 3 秒倒數）。
- **通知提醒**：每換一段發通知，手機或小米手環會震動；可選換段前 5／10 秒先提醒。
- **英語練習模式**：手機完全靜音，只靠通知震動；可搭配英語學習筆記本使用。英語筆記本播放例句時，本 App 會自動讓出聲音並改用時鐘計時。
- **紀錄**：每次運動的時間、RPE、身體感覺，本週次數與連續天數。

## Tabata 時間指導器（tabata.html）
- 網址：<https://chahan1.github.io/walk/tabata.html>。
- **切換運動模式**：兩個畫面最上方都有「間歇快走慢跑｜Tabata」切換列；間歇 App「設定」裡也有「運動模式」。選了會記住，下次從主畫面打開 App 會直接進入上次的模式。
- **畫面**：首頁只有模式選擇、一張計畫卡（全長、每段長度、回合數）和「開始」按鈕；時間、動作、開始方式、提示等設定都收在右上角的設定裡，Tabata 說明收在 ⓘ 裡。
- **預設模式**：經典 Tabata（20 秒／10 秒 × 8，約 4 分鐘）、adidas 15 分鐘（兩個動作交替，3 組，組間 1 分鐘）、入門版（20 秒／20 秒 × 8）、自訂。
- **時間自由設定**：準備、運動、休息、回合數、組數、組間休息、緩和都能調；「逐段調整長度」還能單獨改任何一段的秒數。
- **下一段怎麼開始**：自動接續（可關閉螢幕，提示音做在音軌裡）、每組結束等我、每段都等我（按「開始下一段」才計時）。
- **記住自訂時間**：在「自訂」改過的時間（包含逐段調整和動作名稱）會自動記住；先選其他預設模式，之後再點「自訂」就會還原上次的設定，卡片上也會顯示上次的時間。
- **震動提醒**：每回合運動時間一到就長震兩下；運動開始短震三下；運動的最後 3 秒每秒短震一下（螢幕亮著時，Android）。設定裡有「測試震動」按鈕。螢幕關閉時改發通知，手機和小米手環都會震動（設定裡要先「允許通知」）。
- 動作名稱用逗號分開，運動段會依序輪流並用語音念出；也可選英文提示。

## 第一次使用（小米手機）
1. 用 Chrome 開啟 <https://chahan1.github.io/walk/>，右上選單 →「加到主畫面」。
2. 手機「設定 → 應用程式 → Chrome → 省電策略」改成「無限制」。
3. 要用手環：「小米運動健康」→ 手環 → 應用通知 → 開啟 Chrome。
4. App「設定」頁按「允許通知」，再按「測試手環震動」，10 秒內鎖上螢幕確認會震動。
